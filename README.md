# wik

A git reimplementation in Rust, built to study diff, merge, hashing and graph traversal algorithms.

## About

`wik` is the implementation project for my engineering thesis, _Reimplementing core Git functionality in Rust - an algorithmic study of diff, merge, and graph traversal_.

The goal is not to create a better alternative to Git. The project reimplements a core subset of Git in Rust in order to study how different algorithms for hashing, graph traversal, diff and merge solve each of these problems, to compare their trade-offs, and to assess how well Rust is suited for building a version control system.
